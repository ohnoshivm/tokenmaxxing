# X thread — Premium Model Delegation System

**By [Shivam Kumawat](https://github.com/ohnoshivm) (@ohnoshivm) · AgentKind Labs**

**1/** Most AI “agent systems” aren't optimized. They just make expensive models supervise other models while everyone rereads the same context.

I built a research-backed delegation framework to improve quality while reducing wasted tokens and quota.

**2/** The most interesting benchmark result: Opus 5.5 Medium beats Sonnet 5.5 High on Artificial Analysis Intelligence Index: 51 vs 47.

It also uses fewer output tokens per task: 26K vs 37K. But its estimated API task cost is higher: $1.34 vs $0.88. These are different kinds of efficiency.

**3/** The default intelligence model is now Opus Medium. Opus High is reserved for important, difficult or original decisions. Xhigh/Max are rare, never routine.

**4/** GPT handles implementation. GPT-6 Luna High executes clear, bounded coding tasks. GPT-6.1 Sol High takes complex debugging and advanced engineering.

**5/** Why not give everything to Luna? On Terminal-Bench 4.0, Artificial Analysis reports 5% for Luna High vs 52% for Sol High. Cheap execution only helps when work actually finishes.

**6/** GPT-5.6 Luna handles repetitive intelligent tasks, Haiku backs it up, and ordinary scripts do formatting, validation and other deterministic work.

**7/** We rejected delegation-first. Every new agent costs context, coordination, tool overhead and potentially repeated exploration. Delegate only when specialization, independence or isolation pays for itself.

**8/** Every real model-to-model transfer uses a short contract: objective, confirmed decisions, relevant files, acceptance criteria, actual test results, blockers and next step.

**9/** This is built for a T3-based workspace, but the routing rules are portable. T3 Chat and T3 Code have different capabilities; automatic delegation must be verified in the actual app rather than assumed.

**10/** I published the complete 7,000+ word paper, research links, model routing policy, project instructions, templates and evaluation scorecard.

No made-up savings percentage. Just a system you can test and improve.
